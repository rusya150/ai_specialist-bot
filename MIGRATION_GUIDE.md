# Інструкція з міграції проекту AI Specialist на безкоштовний хостинг

Цей файл містить опис усіх кроків та налаштувань, які необхідно виконати для безкоштовного запуску проекту після внесення змін до коду.

---

## 🛠️ Що вже зроблено в коді:
1. **База даних:** Бекенд тепер підтримує PostgreSQL (Neon/Supabase) через змінну оточення `DATABASE_URL`. Якщо вона порожня — використовується локальний SQLite (`ai_specialist.db`).
2. **Безпека CORS:** Бекенд зчитує дозволені домени зі змінної оточення `CORS_ORIGINS`.
3. **Фронтенд:** Усі API-запити переведені на єдиний конфіг `frontend/src/config.ts`, який використовує змінну оточення `VITE_API_URL`.

---

## 🚀 Крок 1: Створення бази даних (Neon)
1. Перейдіть на [Neon.tech](https://neon.tech/) та зареєструйте безкоштовний акаунт.
2. Створіть новий проект та базу даних.
3. Скопіюйте рядок підключення (**Connection String**) у форматі:
   `postgresql://alex:password@ep-cool-breeze-123456.eu-central-1.aws.neon.tech/neondb?sslmode=require`

---

## 🚀 Крок 2: Деплой бекенду (Koyeb)
1. Зареєструйтеся на [Koyeb.com](https://www.koyeb.com/).
2. Створіть новий **Web Service**, вибравши ваш репозиторій GitHub.
3. Вкажіть папку проекту (якщо потрібно) або залиште за замовчуванням.
4. Додайте такі змінні оточення (**Environment Variables**):
   * `DATABASE_URL` = *Ваш рядок підключення з Neon*
   * `CORS_ORIGINS` = `https://<ваша-адреса-фронтенду>.vercel.app,https://t.me` *(адресу фронтенду можна оновити після його створення)*
   * `TELEGRAM_BOT_TOKEN` = *Токен вашого Telegram-бота*
   * `GROQ_API_KEY` = *Ключ Groq*
   * `GEMINI_API_KEY` = *Ключ Gemini*
5. Після запуску скопіюйте наданий Koyeb URL бекенду (наприклад, `https://ai-specialist-backend-xxx.koyeb.app`).

---

## 🚀 Крок 3: Деплой фронтенду (Vercel)
1. Зареєструйтеся на [Vercel.com](https://vercel.com/).
2. Натисніть **Add New -> Project** та імпортуйте ваш репозиторій.
3. Виберіть папку `frontend` як кореневу для збірки.
4. Додайте змінну оточення:
   * `VITE_API_URL` = `https://ai-specialist-backend-xxx.koyeb.app` *(публічний URL вашого бекенду з Koyeb без косої риски наприкінці)*
5. Натисніть **Deploy**.

---

## 🔄 Авто-ініціалізація бази даних
* При першому успішному старті Koyeb підключиться до бази даних Neon, автоматично створить потрібні таблиці та наповнить їх початковими даними (категорії, промпти, лінки на Notion). Жодних додаткових SQL-скриптів вручну запускати не потрібно!
